# 第34次修改：VOFA FireWater 串口实验

第36次新增平衡角测量：当前步骤请优先阅读BALANCE_MEASUREMENT.md。
进入JOG测量模式或加载实测平衡零点后，旧ANGLE命令停用，CH2/CH3改用测量坐标。
现在只交付源码，请在CCS中自行编译烧录。

固件标识：ROUND-034_FIREWATER_SERIAL_V1。上电停在当前位置，只有 ANGLE 命令会驱动电机；没有任务一、自动归零或球位置 PID。
K230 程序和 UART2 协议保持现状。

## 连接与配置

电脑连接的是 **MSPM0 UART0**，不是 K230 USB 串口：

| USB转串口（3.3V逻辑） | 主板 |
| --- | --- |
| RX | PA10 / UART0 TX |
| TX | PA11 / UART0 RX |
| GND | GND |

如果之前只有波形而命令没有响应，优先检查转串口的 TX 是否连到 PA11。
不要把 5V 电平或 RS232 电平接入 GPIO。
VOFA 选择实际串口号、115200、8N1、无流控、FireWater。
发送使用文本模式，每条命令末尾附加实际 LF 换行（也接受 CRLF）。
不要发送字面量的反斜杠和 n；不要开启定时重复发送标定/角度命令。

## 四条曲线

每20毫秒输出一帧，例如 ball:12.40,8.70,31.00,30.92 后跟换行。

| 通道 | 含义 |
| --- | --- |
| CH0 | 球位置 mm，靠近电机为负、远离电机为正 |
| CH1 | 球速度 mm/s，按新视觉帧差分并低通滤波 |
| CH2 | 电机目标角度 deg，历史实验坐标 |
| CH3 | 电机实际角度 deg，绝对PWM反馈减去49.3°并处理跨圈 |

VOFA 的 Δt 设为20 ms。输出50 Hz不等于相机50 Hz；两帧输出间没有新视觉时会重复最近一次测量。
未标定/视觉过期的 CH0、CH1，尚未下达目标的 CH2，PWM无效的 CH3，均输出 **-9999** 表示无效，不代表真实位置。
标定完成和角度有效后可重新自动缩放曲线。每个通道可单独查看，避免无效哨兵值挤压纵轴。

带 [BOOT]/[SCALE_CAPTURE]/[SCALE_RESULT]/[STATUS]/[ERR] 的行是事件文本，ball: 行才是四通道数据。
在 VOFA 的文本接收区设置“隐藏采样数据帧”，可只看命令响应与错误。
FireWater格式依据：https://www.vofa.plus/docs/learning/dataengines/firewater/

## 串口命令

| 发送内容（末尾附加换行） | 动作 |
| --- | --- |
| HELP | 打印简短命令说明 |
| STATUS | 打印视觉新鲜度、像素、标定状态、绝对PWM角度、电机状态和收发错误计数 |
| CAL,CENTER | 开始新一轮中心采集，清除旧标定 |
| CAL,LEFT | 采集靠近电机的 −50 mm |
| CAL,RIGHT | 采集远离电机的 +50 mm |
| CAL,RESET | 取消采集、清除标定；不会转动电机 |
| ANGLE,31 | 电机到历史实验31°，允许24～40°，可含小数 |
| STOP | 立即取消目标并停止脉冲，保持驱动器使能；同时取消未完成采集 |
| STREAM,OFF | 暂停波形数据，命令和事件文本仍可用；不会停止电机 |
| STREAM,ON | 恢复四通道输出 |

大小写均可，建议按表中格式发送，不加多余空格。命令处理需要完整换行。
按键可不用；保留 PA17 顺序标定快捷方式，PB7 对应 STOP。

## 先做三点标定

1. 固定相机、水管和车体位置。沿水管长度从中心分别量50 mm，做出中心、靠近电机−50 mm、远离电机+50 mm三个标记。对齐的是球心。
2. 发送 STATUS，确认 vision=1、raw_px跟随真实小球，不能是管端或手指。
3. 球心放中心并静止，发送 CAL,CENTER。等待 ACCEPTED 后再移动球。
4. 球心放靠近电机−50 mm处，发送 CAL,LEFT，等待 ACCEPTED。
5. 球心放远离电机+50 mm处，发送 CAL,RIGHT，等待 SCALE_RESULT state=READY。
6. 不再发标定命令，人工依次放回−50、−25、0、+25、+50 mm，每处静止约2秒，保存曲线和对应STATUS。

每个点采12个新帧，像素极差大于8会拒绝；3秒内采不齐、断流超过250毫秒也会拒绝。失败后重复当前点命令。
顺序错误会打印 CAL_ORDER；下一条正确命令仍可继续。球移动期间不要标定。
左右像素方向可以反过来，软件由三点自动确定符号。两段使用各自mm/px。
只有三个标定点正确不等于中间准确，±25 mm是独立验证点。
标定保存在RAM，重启后需重做；先把SCALE_RESULT日志保存给我。

## 电机角度基准

ANGLE,31 指此前测量的31°，不是绝对编码器31°：
本机角度 = PWM绝对角度 − 49.3°（处理360°跨圈）。
例如历史31°对应PWM约80.3°。不要照搬其他方案里的ANGLE,76.3，它超出本机24～40°范围，会拒绝。
首次有效ANGLE会在当前姿态建立软件偏移，再执行目标，不会先走一遍0°。

PWM无效、当前角度不在历史0～42°可操作范围、仍在采集标定或电机已有故障时，会打印原因并拒绝该角度命令；串口和STATUS继续可用。
运动中PWM丢失、闭环故障或10秒仍未到位，会停止脉冲并打印STOP原因。
保持使能表示可能有保持力，STOP不是断电；重新发送有效ANGLE才会重新动作。

第一步先验收视觉尺度。后续再拿掉球做ANGLE,31 → ANGLE,32的小阶跃，记录CH2/CH3。
不要把电机轴角度当成水管倾角，机械水平/平衡角还需要后续实测。
