# 平衡球键盘遥控器（最小版）

Windows + Python 3 的最小键盘遥控。只做相对平衡零点的加减角度和回零，不做PID、扫频、CSV、视觉状态、手动模式状态机、心跳看门狗、机械限位确认或停止脉冲按钮。

## 安装与运行

```powershell
py -3 -m pip install -r requirements.txt
py -3 app.py
```

没有 `py` 启动器就把 `py -3` 换成 `python`，或双击 `run.bat`。Python 必须独占串口，运行前关闭 VOFA 和其它串口助手。

对应固件构建标识：

```text
ROUND-047_MINIMAL_REMOTE_V1
```

## 按键

| 按键 | 动作 |
| --- | --- |
| `→` | 每按一次目标角 +1° |
| `←` | 每按一次目标角 -1° |
| 长按 `→`/`←` | 300 ms 后每 100 ms 连续加/减 1° |
| 松开方向键 | 保持当前目标角，不再累加 |
| `空格` | 回到平衡零点（发送 `BALANCE,ZERO`，目标角归 0） |
| `Esc` | 关闭窗口 |

目标范围固定为相对零点 **-15° ~ +15°**。界面只显示串口连接状态、目标角、实际角。

## 串口命令

```text
ANGLE_REL,+3.0     目标角相对平衡零点 +3°
ANGLE_REL,-2.0     目标角相对平衡零点 -2°
BALANCE,ZERO       回到平衡零点
STATUS             读取实际角（界面每 250 ms 轮询一次）
```

固件对 `ANGLE_REL` 只接受 -15.0 ~ +15.0，与旧的 `ANGLE,24..40` 绝对坐标无关。所有串口写入由一个发送线程串行化，避免并发写导致的 RX_LOST。

## 安全兜底

固件内部保留反馈失效保护：编码器/PWM 反馈丢失或方向错误时立即停止电机并锁存故障，不再继续运动。这不需要上位机界面配合。

首次使用建议先拿掉球，轻按一次 `→` 到 +1°，再按一次 `←` 回 0°，确认方向和反馈正常。
